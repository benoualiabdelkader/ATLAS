# Contributing to ATLAS

First off, thank you for considering contributing to ATLAS! 

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Set up the development environment as per [docs/setup.md](docs/setup.md).
4. Create a new branch for your feature or bug fix: `git checkout -b feature/your-feature-name`.

## Making Changes

- Ensure your code follows the existing style conventions.
- Write clear, commented code where necessary.
- Add tests for new features.
- Update the documentation if your changes affect the setup or architecture.

## Pull Requests

- Push your branch to your fork.
- Open a Pull Request against the `main` branch of the ATLAS repository.
- Provide a clear description of the changes you've made.

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
